# Agenda Tutores Pro

Tema WordPress personalizado para gerenciar tutores, turmas e agendas em contexto educacional.

- Tema customizado chamado "Agenda Tutores Pro"
- Gerencia tutores, turmas e agendas
- Revisão completa do código do tema concluída
- Reformulação visual abrangente do CSS, com design system refinado: tipografia, paleta de cores, estilos de componentes, animações e melhorias de acessibilidade
- Relacionado a um contexto maior de gestão educacional que também envolve integração com Moodle
- Trabalhando na versão 9.25 do tema
- Melhorias visuais aplicadas em style.css: propriedades CSS customizadas, fonte Inter, paleta de cores e sombras
- Componentes de UI aprimorados: cards, tabelas, badges, modais, botões
- Acessibilidade inclui suporte a prefers-reduced-motion
