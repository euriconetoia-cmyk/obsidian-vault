# Cronograma

Sistema para geração e gestão de cronogramas de turmas. Repositório: https://github.com/euriconetoia-cmyk/Cronograma

- Quer testar o sistema para ver o que precisa atualizar
- Está criando um sistema para cadastrar curso/estrutura, turma, equipe e feriados e gerar cronogramas de turmas EaD (modelo: planilha SENAI TST Itumbiara); primeira versão em HTML único com dados no navegador + exportar/importar, datas de encontros presenciais manuais
- Quer que o sistema seja entregue como tema WordPress com plugins, já montado e com todas as páginas estruturadas
- Fluxo de validação planejado: a Unidigit@l cria o cronograma conforme a unidade escolar solicita e envia para a unidade validar (ela ajusta só o cronograma da sua turma); depois de validado fica travado até a Unidigit@l reabrir, e então volta para validação
- Também quer exportar o cronograma em Excel e PDF e ter login/acessos por unidade
- Quer o nome "Unidigital" no lugar de "NIEaD" em todos os textos
- Quer subir a versão WordPress (plugin + tema + interface) para https://github.com/euriconetoia-cmyk/Cronograma-WP
